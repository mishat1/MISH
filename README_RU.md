## Windows: подготовка и запуск

Нужен Python 3.11+. Распакуйте архив в отдельную папку, откройте PowerShell в ней:

```powershell
.\Install-Tools.ps1
.\Start-Windows.ps1 -VerifyAI
```

Первый скрипт скачивает официальную портативную сборку Real-ESRGAN с моделями
и сборку FFmpeg от Gyan, проверяет закреплённые SHA-256 и распаковывает в `tools`.
Глобальная установка не выполняется. Проверенные архивы были скачаны в этой сессии;
сам скрипт загрузки проверен синтаксически, повторная загрузка им не запускалась.
Ссылка FFmpeg указывает на текущий релиз: при обновлении upstream контрольная сумма
может перестать совпадать; скрипт остановится. Не отключайте проверку: обновите
источник и сумму после отдельной проверки новой версии.

Второй скрипт находит инструменты, показывает токен и запускает сервер.
Файлы положите в `Windows_Server/media` либо задайте собственную папку:

```powershell
.\Start-Windows.ps1 -Media 'D:\Movies' -VerifyAI
```

Нейронные режимы появляются **только после настоящего стартового инференса**.
Без `-VerifyAI` доступны только обычные режимы; наличие exe и весов не выдаётся
за проверенный AI. Если AI-проверка не прошла, причины есть в `/api/status`.

Использовать собственные инструменты можно через переменные среды:

```powershell
$env:MISH_FFMPEG = 'C:\Tools\ffmpeg.exe'
$env:MISH_FFPROBE = 'C:\Tools\ffprobe.exe'
$env:MISH_REALESRGAN = 'C:\Tools\RealESRGAN\realesrgan-ncnn-vulkan.exe'
$env:MISH_MODELS_DIR = 'C:\Tools\RealESRGAN\models'
python .\Windows_Server\server.py --host 0.0.0.0 --verify-ai
```

`start_windows.bat` также сохранён; для AI передайте ему `--verify-ai`, а инструменты
должны быть в PATH или указаны в переменных среды. Если PowerShell запрещает скрипты,
используйте приведённую команду Python, не меняя глобальную политику безопасности.

## Подключение Apple TV

На TV введите адрес **Windows-компьютера**, например `http://10.0.0.2:8765`, и токен
из `Windows_Server/server-token.txt`. Адрес `10.0.0.21` из старого чата принадлежал
Apple TV, его нельзя использовать как адрес Windows-сервера.

ПК и TV должны находиться в одной доступной сети; разрешите Python в брандмауэре
только для частной сети. Порт не публикуйте в интернете. HTTP передаёт токен и
видео без шифрования: эта версия рассчитана на доверенную домашнюю LAN.
Токен даёт доступ ко всему выбранному видеокаталогу и запуску обработки.

Откройте каталог, выберите файл, выберите доступный режим, запустите обработку.
Вкладка «Задачи» обновляется каждые 3 секунды. Ссылка появляется только после
проверки готового MP4. Ошибка обработки показывается в задаче.
Для первоначальной проверки можно скопировать `verified-samples/input-64x36.mp4`
в папку media. Исходные MKV/WebM могут не играть в AVPlayer; сначала преобразуйте их.

Bonjour — опциональный показ имён узлов, адрес по-прежнему вводится вручную.
`bonjour_optional.py` требует пакет zeroconf и запускается отдельно; эта ветка не
проверялась в LAN. Значение MISH_PORT должно совпадать с портом основного сервера.

## Обработка: условия и пределы

- Сервер обрабатывает один файл за раз; максимум 8 ожидающих заданий, далее HTTP 429.
- Стандартный выход — 3840x2160; чёрные поля сохраняют пропорции.
- Нейросеть выполняет 4x-инференс, затем результат приводится к выбранному размеру.
- Три обычных режима — FFmpeg denoise/Lanczos/unsharp; это не AI.
- Только SDR. PQ/HLG/Dolby Vision с распознанными метаданными отклоняются.
  Неверно размеченный HDR автоматически определить нельзя.
- Первая аудиодорожка преобразуется в AAC stereo. Субтитры и другие дорожки не переносятся.
- VFR переводится в CFR перед нейронным извлечением кадров; выход использует тот же fps.
- По умолчанию исходник до 600 секунд; для AI максимум 1080p и 18000 кадров.
  Для длинных материалов делите видео. MISH_MAX_SECONDS изменяет лимит длительности,
  но не лимит кадров/разрешения AI.
- До извлечения проверяется консервативная оценка места под PNG-кадры.
- История до 100 заданий хранится в памяти. При перезапуске история теряется;
  ранее готовые MP4 остаются в `Windows_Server/processed`, их можно скопировать
  в media для повторного доступа из каталога. Автоочистки готовых файлов нет.
- При остановке сервера текущая обработка может оборваться; автоматического
  восстановления задания после перезапуска нет. Дождитесь окончания перед закрытием.

## Сборка IPA и вариант «один файл»

На Mac с Xcode/tvOS SDK и XcodeGen:

```bash
cd tvOS
xcodegen generate
```

Откройте проект, задайте свой Team и уникальный Bundle Identifier. Сначала
соберите и выполните XCTest на tvOS Simulator. Затем сопрягите физический Apple TV
и выполните Run. Для IPA используйте Archive/экспорт с подходящим профилем.

Для неподписанного tvOS IPA, который затем подпишет tvsign/Signulous:

```bash
bash build-unsigned.sh
```

Ожидаемый выход: `tvOS/build/MISHUltraVision-UNSIGNED.ipa`. Скрипт предоставлен,
но здесь не выполнялся. Неподписанный IPA требует подписи для вашего устройства.
Сервисы подписи не компилируют Swift. Исходный ZIP нельзя установить как IPA.
В проекте разрешён домашний HTTP через ATS; App Store-публикация и её оформление
не подготовлены. macOS runner может заменить личный Mac для сборки.

## Тесты

Укажите MISH_FFMPEG/MISH_FFPROBE/MISH_REALESRGAN/MISH_MODELS_DIR, затем:

```powershell
python -m unittest discover -s tests -v
```

Полный набор требует GPU, модели и инструменты; он не подменяет инференс заглушкой.
XCTest в tvOS/Tests проверяет кодирование URL/токена и отклонение неверных адресов;
эти тесты ещё не запускались. Отчёт — `TEST-REPORT.txt`, изменения — `AUDIT-RU.md`.
