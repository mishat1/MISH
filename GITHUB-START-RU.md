# Получить MISH IPA через GitHub, без собственного Mac

Подготовлено 26.10.2026. Workflow создан и локально проверен по структуре,
но ещё **не запускался в вашем GitHub**. Наличие этих файлов не означает,
что Swift уже скомпилирован. Первая удалённая сборка может выявить ошибки,
которые нужно будет исправить по сохранённому журналу.

## Первый запуск

1. Распакуйте `MISH-GitHub-ready.zip` в отдельную папку.
2. Войдите в свой GitHub в браузере. Откройте https://github.com/new и создайте
   репозиторий `MISH-UltraVision`. Выберите **Private**, добавьте README при создании.
3. В созданном репозитории выберите **Add file → Upload files**. Перетащите
   **содержимое** распакованной папки: `tvOS`, `scripts`, `.github` и остальные файлы.
   Не загружайте сам ZIP и не помещайте всё в дополнительную внешнюю папку.
   Нажмите **Commit changes** в основную ветку.
4. Убедитесь, что виден файл `.github/workflows/build-tvos.yml`. Если папка `.github`
   не загрузилась, создайте этот путь через **Add file → Create new file** и вставьте
   содержимое файла `build-tvos.yml` из комплекта. Именно этот путь включает сборку.
5. Откройте вкладку **Actions**, слева выберите **Build MISH tvOS IPA**.
   При необходимости разрешите Actions для своего репозитория.
   Нажмите **Run workflow**, выберите основную ветку и подтвердите запуск.
6. Дождитесь зелёного результата. Внизу страницы запуска в **Artifacts** скачайте
   **MISH-tvOS-UNSIGNED-IPA**. GitHub выдаст ZIP; распакуйте его и возьмите
   `MISHUltraVision-UNSIGNED.ipa`.
7. Этот IPA затем нужно подписать для Apple TV через выбранный сервис или
   собственный аккаунт разработчика и установить. Не загружайте ZIP артефакта
   вместо самого `.ipa`. Совместимость установки Signulous с вашим устройством
   и tvOS 26.6 нужно подтвердить в сервисе до оплаты.

В этой настройке запуск выполняется вручную, чтобы загрузка исходников не запускала
macOS-задания сама. Доступность macOS runner и остаток минут зависят от вашего плана
и настроек GitHub; стоимость не обещается. Если GitHub требует оплату, остановитесь
и сначала посмотрите условия аккаунта. Workflow не включает оплату автоматически.

## Что происходит при сборке

- Среда GitHub `macos-15`, Xcode 16.4, tvOS deployment target 18.0.
- XcodeGen создаёт проект.
- Два XCTest выполняются на доступном симуляторе tvOS 18+ в выбранном Xcode.
- Release собирается отдельно для настоящего Apple TV arm64, не для симулятора.
- Проверяется ZIP, Info.plist, платформа AppleTVOS, семейство TV, минимум ОС
  не выше 18.6 и ARM64 Mach-O; создаётся SHA-256.
- Только после успешных этапов публикуется артефакт с неподписанным IPA.

Проверка пакета не заменяет проверку подписи и изображения/звука на Apple TV.
Этот runner не выдаётся за испытание именно tvOS 26.6: точная версия симулятора
и SDK записывается в диагностике. Поддержку 26.6 подтверждаем запуском на устройстве.
Xcode 16.4 выбран из опубликованного состава macos-15; при изменениях образа
workflow может потребовать обновления. Версия XcodeGen фиксируется в отчёте,
а устанавливается из актуального Homebrew, если её нет в среде.

## Если сборка красная

Откройте запуск и скачайте **MISH-build-diagnostics**. Там будут `test.log`,
`build.log`, версии инструментов и `.xcresult`, если соответствующий этап успел
их создать. Передайте журнал в этот чат; пароль и токены присылать не нужно.
При ошибке до этапа диагностики скопируйте текст красного шага из страницы Actions.
Не переименовывайте ZIP исходников в IPA: это не создаёт приложение.

Артефакты настроены на хранение 14 дней. Скачайте результат после успешного запуска.
Apple ID, UDID, сертификат и пароль Apple для этой **неподписанной** сборки не нужны.
Файлы `server-token.txt`, `tools`, собственные видео и сертификаты в GitHub не загружайте.
Gitignore помогает при загрузке через Git; браузерная загрузка его не применяет.
Подготовленный ZIP таких секретов не содержит.
